## ✨ Sobre o projeto

**TARANIS BLACK — Brand Board** é um projeto de identidade visual e apresentação editorial desenvolvido para organizar, documentar e comunicar a direção estratégica e visual da marca TARANIS BLACK.

A proposta combina branding, design editorial e desenvolvimento frontend em uma experiência digital que apresenta os principais elementos da identidade da marca de maneira organizada, visual e acessível.

Mais do que uma apresentação de cores e tipografias, o Brand Board busca construir um sistema visual consistente, capaz de orientar futuras aplicações da marca em diferentes canais e materiais de comunicação.

O projeto também considera a experiência multilíngue, permitindo apresentar o conteúdo em espanhol e português brasileiro.

## 🎯 Objetivos

- Organizar os fundamentos da identidade da marca.
- Documentar os elementos visuais e editoriais.
- Estabelecer uma direção de arte consistente.
- Apresentar referências fotográficas e recursos gráficos.
- Estruturar o universo visual dos produtos.
- Demonstrar possíveis aplicações da identidade.
- Apresentar a campanha editorial **WORK IN FLOW**.
- Disponibilizar uma experiência digital responsiva e multilíngue.
- Facilitar a consulta e a apresentação do material em formato digital e impresso.

## 🎨 Identidade visual

A direção visual proposta combina uma estética contemporânea, arquitetônica e minimalista com uma linguagem editorial premium.

### Paleta cromática

| Cor | Código HEX | Aplicação |
|---|---|---|
| Graphite | `#1E2326` | Contraste, fundos escuros e elementos de destaque. |
| Ivory | `#F4EFE6` | Fundos claros e áreas de leitura. |
| Turquoise | `#17857F` | Destaques e elementos de identidade. |
| Coral | `#FF6B57` | Acentos visuais e pontos de atenção. |

### Tipografia

- **Fraunces:** títulos editoriais e mensagens de destaque.
- **Manrope:** textos, navegação, legendas e elementos funcionais.

### Direção de arte

- Minimalismo contemporâneo.
- Composição editorial e assimétrica.
- Hierarquia tipográfica bem definida.
- Fotografia arquitetônica.
- Uso intencional de espaços negativos.
- Equilíbrio entre informação e expressão visual.

> **Nota:** os elementos visuais apresentados neste projeto constituem uma proposta criativa de identidade e devem ser considerados sujeitos à validação e aprovação da marca.

## 🌐 Experiência multilíngue

O Brand Board contempla duas versões linguísticas:

- 🇪🇸 Espanhol.
- 🇧🇷 Português brasileiro (PT-BR).

A experiência multilíngue foi planejada para apresentar o conteúdo em cada idioma de forma natural, preservando a intenção editorial e a consistência da comunicação.

A localização deve contemplar títulos, textos, navegação, botões e demais elementos visíveis da interface.

## 📱 Design responsivo

A experiência considera diferentes dimensões de tela:

- 🖥️ Desktop — apresentação editorial em telas amplas.
- 📱 Tablet — adaptação de colunas e conteúdos.
- 📲 Mobile — navegação simplificada e leitura vertical.

O objetivo é preservar a hierarquia visual, a legibilidade e a consistência da experiência em diferentes dispositivos.

## 🖨️ Exportação e impressão

O projeto prevê uma apresentação adequada para consulta digital e impressão.

A configuração de impressão deve considerar:

- Formato A4.
- Margens equilibradas.
- Hierarquia editorial.
- Preservação de imagens e cores.
- Controle de quebras de página.
- Remoção de controles de navegação na versão impressa.

A exportação deve ser validada nos dois idiomas antes de ser considerada concluída.

## 🚀 Como executar o projeto localmente

### 1. Pré-requisitos

Antes de começar, tenha instalado:

- [Node.js](https://nodejs.org/)
- npm (gerenciador de pacotes do Node.js)
- [Git](https://git-scm.com/)
- Um editor de código, como [Visual Studio Code](https://code.visualstudio.com/)

### 2. Clonar o repositório

```bash
git clone https://github.com/Orliluq/taranis_black.git
```

### 3. Acessar a pasta

```bash
cd taranis_black
```

### 4. Instalar as dependências

```bash
npm install
```

### 5. Iniciar o ambiente de desenvolvimento

```bash
npm run dev
```

O Vite disponibilizará um endereço local no terminal. Abra esse endereço no navegador para visualizar a aplicação.

### 6. Gerar a versão de produção

```bash
npm run build
```

### 7. Visualizar a versão de produção

```bash
npm run preview
```

> Os comandos acima pressupõem os scripts correspondentes configurados no `package.json`. Consulte esse arquivo caso algum comando não esteja disponível.

## 🔒 Precisão das informações

O Brand Board diferencia referências documentadas de propostas criativas.

Não devem ser tratados como fatos confirmados:
- Características de produtos sem documentação.
- Benefícios técnicos ou comerciais sem evidências.
- Certificações e resultados não comprovados.
- Fotografias conceituais como imagens oficiais de produtos.
- Propostas visuais ainda não aprovadas pela marca.

Essa separação contribui para uma apresentação responsável, consistente e profissional.
